Minecraft Hub v3
=================
الملفات:
- index.html: الرئيسية
- mods.html: مكتبة المودات
- maps.html: مكتبة الخرائط
- mod/mod.html: قالب صفحة تفاصيل مود مستقلة
- admin.html: لوحة التحكم المحلية
- app.js: البيانات والمنطق
- style.css: التصميم

التشغيل:
افتح index.html في المتصفح.

لوحة التحكم:
البيانات التي تضيفها تُحفظ في localStorage داخل نفس المتصفح والجهاز.
هذه ليست لوحة تحكم سيرفر عامة؛ لكي تصبح البيانات مشتركة بين الزوار نحتاج Backend وقاعدة بيانات واستضافة.

التحميل:
روابط المودات الافتراضية تشير إلى صفحات CurseForge. زر التحميل في المود المضاف من لوحة التحكم يفتح الرابط الذي أدخلته.
